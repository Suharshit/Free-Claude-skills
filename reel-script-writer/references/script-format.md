# Script format

## Answer layout

Use this layout in the chat. Replace every `[..]`; keep the headings.

```markdown
## 3 hook options

| # | Formula | Spoken (≤ 2 s) | On-screen (≤ 8 words) |
| --- | --- | --- | --- |
| 1 ⭐ | [formula name] | [line] | [text] |
| 2 | [formula name] | [line] | [text] |
| 3 | [formula name] | [line] | [text] |

**Recommended: 1.** [one-line reason]

## Script: [structure] · ~[S] s · [W] words

| Time | Shot | Voice-over | On-screen text |
| --- | --- | --- | --- |
| 0–2 s | [shot] | [hook] | [on-screen hook] |
| 2–5 s | [shot] | [..] | [..] |
| ... | ... | ... | ... |
| [last 3–5 s] | Face, close | [CTA] | [CTA text, keyword in CAPITALS] |

## Voice-over (read aloud)
> [line one]
> [line two]
> ...

## Fill before filming
- [ ] [X minutes] at [time]: [what to measure or confirm], or cut the line.
```

Then the voice card (only when made or updated), then the one-line follow-up offer.

## Structures

Pick one. The beats are a starting shape; merge or split them to fit the length.

| Structure | Beats | Best for |
| --- | --- | --- |
| **Show how** | Hook → what you need → steps (2–4) → the result, shown → CTA | Tutorials, recipes, setups |
| **Before / after** | Hook → the old way (the pain) → what changed → the new result, shown → CTA | Real improvements with proof |
| **Problem → why → fix** | Hook → what goes wrong → why it happens → the fix → CTA | Common mistakes, honest fails |
| **Behind the curtain** | Hook → show the result → how it was made → what I changed by hand → CTA | Process, build-in-public |
| **Explain it simply** | Hook (question) → everyday analogy → one real example → what it means for you → CTA | Concepts, beginners |
| **Myth vs truth** | Hook (myth) → why people believe it → the truth → proof or example → CTA | Correcting assumptions |
| **Quick list** | Hook (number) → item 1 → item 2 → item 3 → CTA | Tips; keep to 3 items under 45 s |

## Shots

Name a shot for every beat. Change something on screen every 2–4 seconds (new shot, zoom, or new text).

- **Face, close:** talking to camera. Use for the hook and the CTA.
- **Face + [thing]:** face in a corner or split screen while the thing is shown.
- **Screen recording of [what]:** for apps, websites, documents.
- **B-roll of [what]:** hands doing the task, the product, the place.
- **Close-up of [what]:** when the viewer must see a detail or read something.
- **Text card:** full-screen text. Use for one number or one before/after, not more than twice.

Name what's on screen exactly ("close-up of the bubbly starter in the jar"), never "relevant footage".

## Pace

- Speech runs at about 2.3–2.5 words per second.
- 30 s ≈ 70–75 words · 45 s ≈ 105–110 words · 60 s ≈ 140–150 words.
- Count the voice-over words, then set the timings so each beat's words fit its seconds.

## Checks (fix before answering)

- [ ] 3 hooks, 3 different formulas, each within the length limits; one recommended with a reason.
- [ ] Hook spoken in ≤ 2 s; on-screen hook ≤ 8 words; first shot shows a face, the result or motion.
- [ ] The one idea is clear by second 10.
- [ ] Something changes on screen every 2–4 seconds.
- [ ] The result or output is named exactly and shown, not just described.
- [ ] Word count fits the length (2.3–2.5 words per second); timings add up with no gaps.
- [ ] Every voice-over line is one thought, sayable in one breath.
- [ ] Sounds like the voice card: their sentence starts, their order of thought, their words. Nothing fancier than the samples.
- [ ] None of the banned hype or filler words.
- [ ] Every number is from the user or in a `[bracket]`; every bracket is listed under "Fill before filming".
- [ ] No income, follower or "go viral" promises.
- [ ] Exactly one CTA, in the last beat; keyword (if any) in CAPITALS.
- [ ] On-screen text is short: ≤ 8 words per beat.
